# Aura Properties — Website Package

This package contains the responsive static website for Aura Properties.

## Important
All property/hero photographs in `assets/` are original generated real-estate imagery. They are **not screenshots or crops of the Google Maps listing or website reference image**.

### Structure
- `index.html`
- `styles.css`
- `script.js`
- `assets/` — local image and logo assets

Upload the files to GitHub with the `assets` folder preserved at the repository root. `index.html` must remain at the repository root for GitHub Pages.

## Before public launch
Replace any sample property names, prices, statistics, social links, hours, and marketing claims with client-approved information.
